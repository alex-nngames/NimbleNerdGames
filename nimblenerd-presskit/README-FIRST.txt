NIMBLENERD GAMES — GITHUB PAGES PRESS KIT STARTER
Created 6 November 2026

This is a completely static, original HTML/CSS press page inspired by the simple two-column presskit() layout used by Blek.
No PHP, databases, frameworks, installation, build command or paid service required.

QUICK INSTALL
1. Unzip this download.
2. Open your EXISTING GitHub Pages website repository.
3. Upload the included 'presskit' folder to the root of that repository, alongside your existing homepage's index.html.
4. Commit the changes.
5. Visit https://nimblenerdgames.com/presskit/

IMPORTANT: Do NOT replace your website's root index.html. The press kit has its own index.html inside the presskit folder.

BEFORE GOING LIVE
- Replace assets/branding/header-preview.svg with real header art and update the image path in presskit/index.html.
- Replace assets/screenshots/screenshot-01.svg through screenshot-04.svg with actual full-resolution screenshot files. Update each <img src=...> and <a href=...> in index.html if your files use .png or .jpg.
- Add the official game logo and App Store icon to assets/branding/; replace the labelled logo and icon placeholder panels in index.html with proper <img> tags and download links.
- Replace the trailer placeholder with the official trailer embed or link, plus an MP4 download if desired.
- Confirm final release date, UK price, platform details, team credits and contact email.
- Remove the yellow 'Template preview' banner from index.html.
- When actual screenshots are ready, make a ZIP of them and add a download link in the Images section.
- The studio logo at the top uses the existing website file ../svg/logo.svg when published. If the site changes that path, update or remove the img tag.

EASY EDITS
- All public text is in presskit/index.html (plus the downloadable plain-text version at assets/press-copy.txt).
- All layout/colours/spacing are in presskit/styles.css.
- No JavaScript is necessary for the site.
- The website URL and email are currently taken from your existing public website.

CAVEAT
The screenshot and header artwork SVG files are labelled PREVIEW placeholders; they are not screenshots from the game and should not be included in a published press kit.

DESIGN CREDIT
Based on the general presskit() format originally created by Rami Ismail. No Blek logos, game graphics, original webpage source code, photographs or proprietary assets were copied.
